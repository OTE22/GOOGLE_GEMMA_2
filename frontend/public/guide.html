One local model converts every supported input into a vector: a list of 768 numbers. The model's learned representation lets different formats be compared.

Native input → Local encoders → Shared vector
[0.014, −0.032, 0.009, … 768 values]

Prompts and processing matter

Text queries use SearchQuery and document passages use Document. The similarity experiment uses SentenceSimilarity on both inputs. Raw media gets no text prefix. Audio is decoded to mono 16 kHz; longer recordings and videos are divided into timestamped segments within the shared token budget.

The model uses float32 or bfloat16 rather than float16. GPU acceleration is selected when available; CPU inference may be slow. Displayed timings are measurements on the current machine, not universal benchmarks.

One space.
One collection.

All normalized vectors live together in a persistent Chroma collection. Metadata links each vector to the original file and, where relevant, a page or time range.

Text · Images · Audio · Video

Conceptual approximate 2D projection. These illustrative points are not measured embeddings. The actual space has 768 dimensions, and reducing it to a page loses information.

Keep the source attached

The original media stays on disk. Stable content hashes connect search results to source files. Audio and video segments retain start and end times so a match can be checked in context.

Search for the idea.
Find it in any format.

A text, image, or audio query becomes a vector using the same model. The system ranks stored vectors by cosine similarity, which compares their directions.

“Workers wearing protective equipment”
↓ query vector ↓
Policy passage · Safety image · Briefing · Video clip

Similarity is evidence for ranking

A score is not a probability that the result is correct. Inspect the original source, page, or timestamp to judge relevance. The interface shows actual retrieved matches, scores, and latency.

Keyword search counts literal terms in document text. Semantic search can connect related ideas even when their words or formats differ. Results depend on your files and query.

Try it: compare “An employee applied for annual leave” with “A worker requested vacation” and an unrelated server-temperature sentence. Measure the similarities without assuming an outcome.

ONE SPACE / FIELD GUIDE / 05

Answers need
readable evidence.

The lightweight LangGraph agent searches the unified collection and evaluates whether readable excerpts are available. If needed, it rewrites the query and searches once more, for a maximum of two retrieval attempts.

Question → Retrieve → Evaluate
↓ optional rewrite and one more search ↓
Evidence → OpenRouter → Cited answer

A vector is not a transcript

A text-only LLM cannot inspect an arbitrary image, audio, or video embedding. It receives extracted document text or documented captions and synthesis scripts from the generated demo. For other media, it must acknowledge missing evidence.

Privacy boundary: files, model weights, embeddings, and retrieval remain local. Chat questions and selected readable evidence are sent externally to OpenRouter. The API key is read only by the backend.
